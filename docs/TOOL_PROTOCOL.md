# Tool Protocol

A Vynnra tool is defined by:

```text
id
name
description
inputSchema
outputSchema
requiredCapabilities
riskLevel
requiresConfirmation
supportsCancellation
supportsVerification
```

## Result

```text
SUCCESS
PARTIAL
FAILED
CANCELLED
BLOCKED
```

Tool implementations must return structured results. Human-readable text is generated by the agent/UI layer rather than becoming the only source of truth.

## Capability examples

```text
SCREEN_READ
SCREEN_INTERACT
ACCESSIBILITY_CONTROL
FILE_READ
FILE_WRITE
BROWSER_CONTROL
WEB_SEARCH
MICROPHONE
NOTIFICATION_ACCESS
OVERLAY
BACKGROUND_EXECUTION
```

Capabilities are checked at runtime. The absence of a capability is represented explicitly so the agent can explain what is blocked and choose a safe alternative.
